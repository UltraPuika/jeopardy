End Game Stage Trigger

Checked at the start of every round (once each team has had one turn). If fewer clues remain than there are teams (e.g. 4 teams, 1 clue left), End Game mode triggers. Control is automatically unselected to start a round for all teams (FFA mode, 100% point value). Answering correctly in this stage selects that team for board control.
